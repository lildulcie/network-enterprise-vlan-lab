Enterprise VLAN Routing Lab

Overview

This project simulates a small enterprise network using Cisco Packet Tracer.

Features

VLAN segmentation
Inter-VLAN routing
Access and trunk port configuration
Server deployment
Web server connectivity
Basic enterprise network topology

VLAN Structure

VLAN 10: IT
VLAN 20: HR
VLAN 30: SERVER

Technologies Used

Cisco Packet Tracer
Cisco Router 2911
Cisco Switch 2960

Result

PCs from different VLANs can communicate successfully.
Web server is reachable from client VLANs.
Enterprise network simulation completed successfully.
